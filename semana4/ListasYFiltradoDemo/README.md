# ListasYFiltradoDemo

Mini proyecto de la **semana 4** enfocado en:
- uso de la interfaz `List`
- implementación concreta con `ArrayList`
- recorrido con `for-each`
- búsqueda y filtrado con `contains()`

## Idea pedagógica
Permite enseñar polimorfismo básico al declarar la colección como `List`, dejando la implementación concreta como `ArrayList`.
