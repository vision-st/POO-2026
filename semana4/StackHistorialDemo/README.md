# StackHistorialDemo

Mini proyecto de la **semana 4** para enseñar la estructura `Stack`.

## Tema trabajado
- comportamiento LIFO
- inserción con `push()`
- eliminación con `pop()`
- consulta de estado de la pila

## Idea pedagógica
Representa un historial de acciones de videojuego, un caso mucho más natural para explicar por qué la última acción es la primera que se deshace.
