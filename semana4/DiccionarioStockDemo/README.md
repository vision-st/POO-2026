# DiccionarioStockDemo

Mini proyecto de la **semana 4** orientado al uso de `HashMap` como diccionario.

## Tema trabajado
- clave y valor
- inserción con `put()`
- acceso con `get()`
- recorrido de entradas
- búsqueda por clave

## Idea pedagógica
Sirve para mostrar por qué un `HashMap` es mejor que una lista cuando se necesita acceder rápidamente a un dato asociado a una clave.
