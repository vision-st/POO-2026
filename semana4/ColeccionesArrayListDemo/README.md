# ColeccionesArrayListDemo

Mini proyecto de la **semana 4** para introducir el uso de `ArrayList` en Java.

## Tema trabajado
- colección dinámica
- inserción con `add()`
- acceso con `get()`
- eliminación con `remove()`
- recorrido con `for-each`

## Idea pedagógica
Este proyecto muestra por qué `ArrayList` resulta más flexible que un arreglo fijo cuando necesitamos agregar o quitar elementos durante la ejecución.
