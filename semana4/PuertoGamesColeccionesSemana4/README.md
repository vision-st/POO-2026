# PuertoGamesColeccionesSemana4

Proyecto integrador de la **semana 4** para trabajar colecciones provistas por el lenguaje.

## Contenidos cubiertos
- lectura de datos desde archivo externo
- conversión de texto a objetos Java
- almacenamiento en `ArrayList`
- recorrido con `for-each`
- búsqueda por coincidencia
- filtrado por género
- separación lógica en paquetes `model`, `data` y `ui`

## Idea pedagógica
Este proyecto conecta la teoría de colecciones con una situación más realista: cargar videojuegos desde un archivo y operar sobre ellos sin hardcodear todo en el `main`.
