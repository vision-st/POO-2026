# GestorVideojuegosSincronica

Proyecto pequeno de apoyo para una clase sincronica sobre lectura de Excel con Java.

## Objetivo
Mostrar de forma acotada:
- uso de Maven
- dependencia Apache POI
- lectura de un archivo `.xlsx`
- transformacion de filas en objetos de dominio
- separacion en paquetes `model`, `data` y `ui`

## Estructura
- `model/VideoJuego`: representa el dato
- `data/GestorVideoJuegos`: carga y administra los videojuegos
- `ui/Main`: punto de entrada

## Uso sugerido en clase
Este proyecto sirve para una demostracion guiada paso a paso antes de saltar al proyecto principal de semana 5.
