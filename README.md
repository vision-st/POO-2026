# POO-2026

Repositorio de proyectos semanales de la asignatura **Programación Orientada a Objetos (POO)** para el año 2026.

## Objetivo del repositorio

Este repositorio concentra el trabajo desarrollado semana a semana en clases, manteniendo una estructura simple, ordenada y fácil de navegar. Cada carpeta `semanaX` representa una semana de trabajo y dentro de ella se almacenan los proyectos Java correspondientes.

## Estructura general

```text
POO/
├── semana1/
├── semana2/
├── semana3/
├── semana4/
├── semana5/
├── semana6/
├── semana7/
├── semana8/
├── semana9/
└── semana10/
```

## Criterio de organización

- Cada semana contiene uno o más proyectos Java según la actividad realizada.
- Cada proyecto puede incluir su propio `README.md` con la explicación técnica y teórica de la actividad.
- El repositorio excluye archivos generados por IDEs, compilación y configuraciones locales innecesarias.

## Estado actual

- `semana2`: contiene el proyecto **RobotsSemana2**.
- `semana5`: contiene proyectos de apoyo sobre organizacion de proyectos Java, lectura de Excel con Apache POI, manejo de rutas, version portable del proyecto PuertoGames y una variante Swing.
- Las demás semanas quedan preparadas para incorporar futuros trabajos.

## Tecnologías base

- Java
- Maven
- IntelliJ IDEA
